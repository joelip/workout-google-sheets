# Repository instructions

- Always prefer TypeScript for application code, scripts, tests, migrations tooling, and reusable automation in this repository.
- Use the latest stable Bun runtime and Bun-native APIs where practical.
- Use `bun`, `bun run`, and `bun test` rather than Node.js, npm, pnpm, Jest, or Vitest.
- Add another language only when TypeScript/Bun cannot reasonably support the required platform or tooling, and document that exception.
