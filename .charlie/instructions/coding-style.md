# Coding style and preferences

Rules and preferences on coding style within the repo.

## Scope

All typescript written in this repo.

## Rules

- [R1] Prefer breaking up larger serialized code into smaller, specific functions.
- [R2] Write tests for functionality that is labeled as essential in comments.
- [R3] If refactoring code, write tests that pass with the existing implementation first and then write the new code to ensure no change in end functionality.
